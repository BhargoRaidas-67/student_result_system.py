# Student Result Management System

A simple Python program to calculate student percentage, grade and show result summary.

**Features:**
- Takes marks of 5 subjects
- Calculates total and percentage
- Shows grade (A, B, C, D, F)
- Proper error handling

**Technologies Used:**
- Python
- Input handling
- Conditional statements (if-elif-else)
- Try-Except for error handling
